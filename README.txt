# Linguist — менеджер карток для вивчення мов

Невеликий навчальний проєкт на **Python** та **SQLAlchemy ORM**. Він демонструє роботу з SQLite-базою даних і повний набір CRUD-операцій (створення, читання, оновлення, видалення) для користувачів, колод і карток слів.

## Можливості

- створення та редагування користувачів;
- зміна пароля з перевіркою поточного пароля;
- створення, перейменування й видалення колод;
- створення, перегляд, часткове оновлення та видалення карток;
- пошук карток за частиною слова, перекладу або підказки без урахування регістру;
- автоматичне створення SQLite-бази під час першого запуску;
- набір перевірок для всіх реалізованих операцій.

## Технології

- Python 3
- [SQLAlchemy](https://www.sqlalchemy.org/) 2.0+
- SQLite (вбудована база даних — окремий сервер не потрібен)

## Швидкий старт

1. Клонуйте репозиторій і перейдіть до його папки.

2. За бажанням створіть та активуйте віртуальне середовище:

   ```bash
   python -m venv .venv
   source .venv/bin/activate
   ```

   У Windows:

   ```powershell
   .venv\Scripts\Activate.ps1
   ```

3. Встановіть залежності:

   ```bash
   pip install -r requirements.txt
   ```

4. Запустіть перевірки:

   ```bash
   python test_linguist.py
   ```

Після першого імпорту `linguist.py` у корені проєкту створюється файл `linguist.db`. Тестовий скрипт щоразу починає з чистої бази, тому не використовуйте його для бази з важливими даними.

## Модель даних

| Сутність | Основні поля | Призначення |
| --- | --- | --- |
| `User` | `id`, `name`, `email`, `password` | Обліковий запис власника колод і карток. Поле `email` унікальне. |
| `Deck` | `id`, `name`, `user_id` | Іменована колода, що належить користувачу. |
| `Card` | `id`, `user_id`, `word`, `translation`, `tip` | Картка з англійським словом, українським перекладом та необов’язковою підказкою. |

`user_id` у колоді та картці є зовнішнім ключем на `users.id`.

## Приклад використання

```python
import linguist as ln

# Створити користувача
user = ln.user_create("Олена", "olena@example.com", "secret123")

# Створити колоду та картку
deck = ln.deck_create("Базова лексика", user.id)
card = ln.card_create(
    user.id,
    "apple",
    "яблуко",
    "Згадайте яблучний пиріг.",
)

# Знайти картки за фрагментом тексту
for result in ln.card_filter("яблук"):
    print(result.word, "—", result.translation)

# Оновити лише переклад
ln.card_update(card.id, translation="зелене яблуко")
```

## Доступні функції

| Сутність | Функції |
| --- | --- |
| Користувачі | `user_create`, `user_get_by_id`, `user_update_name`, `user_change_password`, `user_delete_by_id` |
| Колоди | `deck_create`, `deck_get_by_id`, `deck_update`, `deck_delete_by_id` |
| Картки | `card_create`, `card_get_by_id`, `card_filter`, `card_update`, `card_delete_by_id` |

Функції пошуку за `id` та оновлення повертають `None`, якщо запису не існує. Функції видалення повертають `True` або `False` залежно від результату.

## Важливі примітки

- Проєкт навчальний: пароль наразі зберігається у відкритому вигляді. Для реального застосунку слід використовувати надійне хешування паролів.
- Колоди та картки обидві прив’язані до користувача, але картка ще не має прямого зв’язку з конкретною колодою.
- У поточній реалізації видалення користувача не видаляє автоматично його залежні записи.
